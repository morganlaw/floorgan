# FloorGAN - Floorplan & Furniture Placement Planner

Interactive web application for floorplan layout drafting, furniture placement, and spatial visualization.

**Live Demo**: [m7w.ca/floorgan](https://m7w.ca/floorgan/)

## Features (Planned)
- 2D Canvas layout editor (walls, doors, windows, dimensions).
- Furniture catalog with drag-and-drop placement, rotation, and snapping.
- Scale calibration and grid system (metric / imperial).
- Export / import floorplans (JSON, image, SVG).
- 3D visualization preview (optional Three.js integration).
